🧩 Sudoku Game
A fully functional, interactive Sudoku puzzle game. This project provides a clean interface for solving Sudoku puzzles with real-time validation and logic-based grid generation.

🚀 Getting Started
Prerequisites
You only need a modern web browser (Chrome, Firefox, Edge, or Safari) to run this project locally.

Installation
Clone the repository:

Bash
git clone https://github.com/sunny-kumar-rana/Sudoku-game.git
Navigate to the directory:

Bash
cd Sudoku-game
Launch the game:
Open the index.html file in your preferred browser.

🎮 How to Play
Objective: Fill the 9x9 grid so that each row, each column, and each of the nine 3x3 subgrids contains all of the digits from 1 to 9.

Input: Click on a cell and type a number or use the provided on-screen keypad.

Rules:

No number can be repeated in a single row.

No number can be repeated in a single column.

No number can be repeated within a 3x3 box.
